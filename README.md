# 上下班打卡

本地记录上下班时间的渐进式网页应用（PWA）：一点打卡、本月平均、月度预测（接下来每日平均）、剩余上班天数。三个分页：打卡、历史与趋势、设置。没有账号、没有服务器、没有统计，数据只保存在你自己的设备上。

## 功能

- **一键打卡**：圆形大按钮，上班红、下班绿，点一下记录当前时间。上下班时间都向下取 15 分钟（比如 10:07 算 10:00）。
- **进行中班次**：正在上班时显示“几点开始，已过几小时”，每秒更新。
- **时长显示**：所有时长都是一位小数小时（8.3小时），不显示分钟；打卡时刻本身是 HH:MM。
- **本月平均**：只算已下班的天数；进行中的班次不计入。首页打卡下方直接显示本月平均和月度预测。
- **月度预测**：接下来每日平均（按 8.1 的月平均下限规划，精确到最近 0.25 小时）+ 已完成天数平均 + 剩余上班天数。剩余天数默认是明天起到月底的工作日（周一至周五），自动扣除美国联邦法定假日；可以点数字直接改或用 −/+ 调，改过的月份会记住，点“恢复自动”回到自动计算。
- **历史记录**：每天一张卡片，最新在前；可以编辑、删除；支持跨夜班次（算在上班那天）。历史页顶上有范围切换（周 / 月 / 全部）和月份选择（‹ › 切换月份，点月份可以跳转），看过去的月份时只显示那个月的数据。
- **补录**：可以补填过去某一天的上下班时间。
- **趋势图**：按所选范围画每日工时柱状图，周末也列出来（显示 0），法定假日不列；没记录的工作日显示为空；点一根柱子看那天的上下班时间和工时，当天高亮。
- **中英文切换**：在设置页里，选了会记住，默认中文。
- **离线可用**：安装后（Service Worker 缓存）没网也能打开和打卡。

## 你的数据

- 存在这台设备的浏览器 IndexedDB 里（数据库名 `clock-in`），IndexedDB 不可用时才退到 localStorage。换设备、清网站数据、卸载应用都会丢数据——**记得定期导出备份**。
- **导出备份**：下载一个 JSON 文件；**导入备份**：按日期合并，文件里的日期会覆盖本地同一天的记录。
- 备份文件格式：`{"app":"clock-in","version":1,"days":[{"date":"2026-01-05","clockIn":"09:00","clockOut":"18:00","note":""}], ...}`

## 部署到 GitHub Pages

1. 在 GitHub 上新建一个公开仓库，把这里的文件推到 `main` 分支。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。`.github/workflows/deploy.yml` 会在每次 push 到 `main` 时自动发布。
3. 打开 `https://yuew233.github.io/Checkin-Tracker/` 就能用。所有资源路径都是相对路径，放在子路径下也能正常工作。

## 在 iPhone 上安装

1. 用 Safari 打开上面的地址。
2. 分享 → **添加到主屏幕**。
3. 从主屏幕打开使用。注意：主屏幕版和 Safari 标签页是两份独立存储，备份要从主屏幕版里导出。

## 本地运行

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

不需要构建步骤。Node 仅用于检查：`node --check src/js/*.js`。
